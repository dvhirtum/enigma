## The Enigma and its procedures

| Term | Meaning |
|---|---|
| Äußere Einstellung | Outer settings: the plugs and the rotor positions, set by the radio operator. |
| Doppelbuchstabentauschtafel, Tauschtafel | Bigram table that swaps pairs of letters to hide the indicator groups. |
| Funkspruch | Radio message. |
| Grundstellung | Starting position of the rotors, given by the daily key. |
| Innere Einstellung | Inner settings: the reflector, rotor order and ring settings, set by an officer. |
| Kenngruppenbuch | Indicator book: trigrams in numbered columns. |
| Ringstellung | Ring setting of a rotor, 01–26. |
| Schlüsselkenngruppe | Trigram that identifies the network, and so the key sheet. |
| Schlüsselkreis | Radio network sharing one key, such as Hydra or Triton. |
| Schlüsseltafel | Key sheet: a month of daily keys. |
| Spruchschlüssel | Message key: the rotor start for the message itself. |
| Steckerverbindungen | Plugboard connections. |
| UKW (Umkehrwalze) | Reflector. |
| Verfahrenkenngruppe | Trigram that, typed at the Grundstellung, gives the Spruchschlüssel. |
| Walzenlage | Rotor order. |
| Zuteilungsliste | Allotment of Kenngruppenbuch columns to networks. |

## Terms in the messages

The words and abbreviations in the [Bombe](bombe/README.md)'s historical intercepts and exercises. Navy messages were written without spaces and with these conventions:

- CH is written Q (SQ for SCH), Ä, Ö and Ü as AE, OE and UE, and ß as SZ.
- X stands for a full stop or a gap between words.
- Numbers are spelled out, one digit at a time: NUL, EINS, ZWO, DREI, VIER, FUENF, SEQS, SIEBEN, AQT, NEUN.
- A grid square (QU) has its two letters tripled: QU AAA CCC VIER NEUN NEUN ZWO is square AC 4992.
- A name is written between two Js, as in STEUERE J TANAFJORD J AN.

### The Army messages of Operation Barbarossa

| Term | Meaning |
|---|---|
| AUFKL ABTEILUNG | Aufklärungsabteilung: reconnaissance battalion. |
| ANGETRETEN | Moved off, set out. |
| ANGRIFF | Attack. |
| ANFANG | Head (of a column). |
| DREI GEHT LANGSAM ABER SIQER VORWAERTS | Number 3 is advancing slowly but surely. |
| FLIEGERSTRASZE | A road named in the report. |
| INF RGT | Infanterieregiment: infantry regiment. |
| KM | Kilometres. |
| LVI A.K. | LVI (56th) Armeekorps: the army corps the reports were sent to. |
| NORDWESTL, OSTW | North-west of, east of. |
| RIQTUNG | Direction, towards. |
| ROEM EINS | Roman one: I, the first battalion. |
| SS-T DIV KDR | Commander of the SS-Totenkopf division, who sent the reports. |

Place names, such as KURTINOWA, SEBEZ, DUBROWKI, OPOTSCHKA and KAMENEC, are written twice.
