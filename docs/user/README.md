# Enigma user guide

This application simulates the Enigma M3 and M4 used by the Kriegsmarine. It covers the machine, the monthly key sheets and the Navy indicator procedure for sending and receiving messages.

## Contents

1. [The Enigma in the Kriegsmarine](history.md): how the machine and the Navy's procedures were used, and how they were broken.
2. [The machine](machine.md): the header, the three views, and setting up rotors, reflector and plugs.
3. [Key sheets](key-sheets.md): generating, importing, printing and applying daily keys, or setting them up by hand.
4. [Sending by hand](sending-by-hand.md): encrypting a message yourself, step by step, with a worked example.
5. [Receiving by hand](receiving-by-hand.md): decrypting a message yourself, plus two historical messages to try.
6. [Operator mode](operator-mode.md): the same procedures with the application guiding each step.
7. [Glossary](glossary.md): the German terms used in the application.

## Quick start

1. Open **Key sheets** (the panel button at the top right) and click **Generate**. Choose a model and a year, and click **Generate**. Then choose a sheet, such as Triton for this month.
2. Click **Apply** on a day. The machine is set up with that day's key.
3. Open **Operator mode** (the message pad button) and click **Send a message**. Follow the steps.
4. Copy the radio message, click **New message**, paste it under **Received message** and receive it again.

When you know the steps, try them without operator mode: see [Sending by hand](sending-by-hand.md).
