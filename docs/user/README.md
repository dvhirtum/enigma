# Enigma user guide

This application simulates the Enigma M3 and M4 used by the Kriegsmarine. It covers the machine, the monthly key sheets and the Navy indicator procedure for sending and receiving messages.

## Contents

1. [The machine](machine.md): the header, the three views, and setting up rotors, reflector and plugs.
2. [Key sheets](key-sheets.md): generating, writing, importing and applying daily keys.
3. [Operator mode](operator-mode.md): sending and receiving a message step by step.
4. [Glossary](glossary.md): the German terms used in the application.

## Quick start

1. Open **Key sheets** (the panel button at the top right) and click **Generate**. Enter a network name, such as `Triton`, and a month.
2. Click **Apply** on a day. The machine is set up with that day's key.
3. Open **Operator mode** (the message pad button) and click **Send a message**. Follow the steps.
4. Copy the radio message, click **New message**, paste it under **Received message** and receive it again.
